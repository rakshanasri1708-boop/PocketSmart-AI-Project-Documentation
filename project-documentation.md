# PocketSmart-AI – Project Documentation

## 1. Project Introduction

PocketSmart-AI is an AI-powered smart budget planner and recommendation assistant. It is designed to help users track daily expenses, receive budget recommendations, and get smart saving tips.

## 2. Project Objective

The main objective is to provide a simple application that helps users manage their expenses and make better budgeting decisions with the support of AI.

## 3. Technologies Used

- Python
- Streamlit
- Google Gemini AI

## 4. Project Features

- Daily expense tracking
- Budget planning
- AI-based budget recommendations
- Smart saving tips
- Simple user interface

## 5. System Workflow

1. The user enters expense-related information.
2. The application processes the information.
3. Google Gemini AI generates recommendations.
4. The application displays the budget recommendations and saving tips.

## 6. Development

The application is developed using Python and Streamlit. Google Gemini AI is used to provide AI-based recommendations.

## 7. Testing

The application is tested to verify user input, application processing, AI recommendations, and the display of saving tips.

## 8. Expected Result

PocketSmart-AI provides a simple way for users to understand their expenses, plan their budget, and receive AI-powered saving suggestions.

## 9. Conclusion

PocketSmart-AI combines budgeting and AI recommendations in a simple application. It aims to make personal expense management easier and more understandable for users.
